# Nike - Novas Ideias e Funcionalidades

Projeto de melhoria para o site da Nike, com foco em criar uma experiência de compra mais moderna, personalizada e interativa.

### Objetivo
Criar novas ideias e funcionalidades para melhorar o site da Nike.

### Ideias Novas
- Provador virtual com câmera (Realidade Aumentada)
- Personalização de produtos em 3D (Nike By You)
- Busca por objetivo: correr, treinar, casual
- Filtro de produtos sustentáveis (Move to Zero)

### Funcionalidades Novas
- Comparador de produtos lado a lado
- Checkout em 1 clique
- Rastreio de entrega gamificado / no mapa
- Integração com Nike Run Club e Training Club
- Lista de desejos compartilhável
